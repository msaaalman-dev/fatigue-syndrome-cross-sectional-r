# Analysis Plan

## Study design

Cross-sectional study.

## Main outcome

Fatigue measured using the 11-item Chalder Fatigue Questionnaire (CFQ-11).

## Main explanatory measures

- Depression symptoms measured using PHQ-9
- Anxiety symptoms measured using GAD-7
- Body mass index (BMI)
- Demographic and behavioral characteristics

## Statistical workflow

1. Data cleaning and quality checks
2. CFQ-11, PHQ-9 and GAD-7 scoring
3. Internal consistency using Cronbach's alpha
4. Descriptive statistics
5. Normality assessment using histograms, Q-Q plots and Shapiro-Wilk tests
6. Independent-samples t-tests for two-category grouping variables
7. One-way ANOVA for multi-category grouping variables
8. Tukey HSD for academic-year comparisons
9. Spearman correlations
10. Multiple linear regression
11. Regression diagnostics
12. Research figures

## Interpretation

Because the study is cross-sectional, associations should not be described as
causal effects. The regression model estimates adjusted associations with the
CFQ-11 fatigue score.
